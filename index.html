Penalty Shootout Game

Interactive browser game · Vanilla JS + Canvas 2D

Penalty Shootout Game

A fully self-contained penalty shootout game built entirely with hand-drawn Canvas graphics — no image assets or external libraries. Every visual, from the stadium atmosphere to the ball's stitched panels, is procedurally rendered.

Highlights

  • Adaptive difficulty — the goalkeeper's shot-reading accuracy and save rate scale dynamically with the player's win streak, creating natural rubber-band tension.
  • Physics-driven animation — ball flight uses a sine-based arc with spin, motion trails, and a shadow that shrinks as it lifts off the ground.
  • Procedural 3D illusion — a true pentagon/hexagon ball pattern with directional lighting and a fixed specular highlight creates a glossy spinning effect entirely in 2D Canvas.
  • Perspective rendering — pitch lines and mow stripes converge toward a vanishing point, while the net sags with bezier curves and ripples on impact.
  • Fully responsive — the game resizes cleanly across desktop and mobile devices with touch support.
