SHEET 01 / ABOUT

A developer who sketches first.

I'm a graduate of Edge Hill University with a Bachelor's with Honours in Web Design and Development. I enjoy creating modern, user-focused digital experiences by combining strong design principles with clean, responsive code.

My experience spans the full web design and development process, from user research, wireframing, and interface design in Figma to building responsive websites and web applications using HTML, CSS, JavaScript, PHP, Python, Laravel, WordPress, Java, and SQL. I also use Git and GitHub for version control and collaborative development, ensuring projects remain organised and maintainable.

Throughout my degree, I treated every project as if it were for a real client — starting by understanding user needs, planning intuitive user journeys, designing accessible interfaces, and developing high-quality, responsive solutions. I have experience applying user-centred design, usability testing, accessibility standards including ARIA, and UX best practices to create websites that are both functional and engaging.

03

Accessible Museum Collection

An accessible, responsive web application that allows users to explore museum artefacts from the Victoria & Albert Museum using its public API. The project was designed with usability and inclusivity in mind, following WCAG 2.1 accessibility guidelines to provide an engaging experience for all users.

HTML5 CSS3 JavaScript REST API WCAG 2.1
accessible-museum.netlify.app
  • Integrated the Victoria & Albert Museum API to dynamically display museum artefacts and detailed object information.
  • Developed a fully responsive interface using HTML5, CSS3 and JavaScript for desktop, tablet and mobile devices.
  • Implemented accessibility features including semantic HTML, keyboard navigation, screen reader support and WCAG 2.1 compliant colour contrast.
  • Designed an intuitive browsing experience with searchable collections, detailed artefact pages and responsive image galleries.
  • Enhanced usability through accessible layouts, performance optimisation and interactive JavaScript components.
